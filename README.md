# mcdp-format2-py

Python bindings for MCDP Format 2

## Installation

```bash
pip install mcdp-format2-py
```

## Development

Install in development mode:

```bash
pip install -e ".[dev]"
```

Run tests:

```bash
pytest
```

## Usage

```python
import mcdp_format2_py

# Your code here
```
